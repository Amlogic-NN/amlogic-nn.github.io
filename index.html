New to the terminology?

Open a term for a plain-language explanation.

NPU

Neural Processing Unit: the hardware accelerator that runs supported model operations.

ADLA

The compiled model format used by the Amlogic runtime. Choose a package compiled for your platform.

SDK

Software Development Kit: APIs, libraries and examples used to integrate inference into an application.

Toolkit

Tools for importing, quantizing, compiling and validating models.

Runtime

The software on the device that loads the compiled model and executes inference.

Quantization

Represent weights or activations at lower precision to reduce storage or computation. Validate accuracy afterwards.

Calibration

Representative input samples used to determine activation quantization parameters for relevant quantization modes.

CNN

Convolutional Neural Network: commonly used for image classification, detection and other perception tasks.

LLM

Large Language Model: generates or processes language, for example conversation and summarization.

VLM

Vision-Language Model: processes images together with language.

FPS

Frames per second. Higher means more inputs processed per second under the stated test conditions.

TTFT

Time to first token: the delay before the first generated token. Usually reported in milliseconds.

Agent

An application that uses a model together with tools and application logic to complete a task.

MCP

Model Context Protocol: a protocol for connecting applications to tools and data.

nnserver

A device-side service used by the full Toolkit to run inference remotely from an x86 PC over ADB.

w8a8 / w4a16

Precision notation for weights and activations. Check the model configuration for the exact integer or floating-point types.

Publish & Customize

  1. Upload this file as index.html to the root of your amlogic-nn.github.io repository.
  2. Open Settings → Pages. Select Deploy from a branch, main, and /(root). Save.
  3. Visit https://amlogic-nn.github.io/ after deployment completes.
  4. Edit the RESOURCES array to update names, descriptions, tags, release status and URLs.
  5. Cards without a URL show “Coming Soon”. Check each resource against its project documentation before publishing.

Reference scenario cards describe possible application workflows. They do not imply released projects or one-click deployment.
