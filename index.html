Publish & Customize

  1. Upload this file as index.html to the root of your amlogic-nn.github.io repository.
  2. Open Settings → Pages. Select Deploy from a branch, main, and /(root). Save.
  3. Visit https://amlogic-nn.github.io/ after deployment completes.
  4. Edit the RESOURCES array to update names, descriptions, tags, release status and URLs.
  5. Cards without a URL show “Coming Soon”. Check each resource against its project documentation before publishing.

Reference scenario cards describe possible application workflows. They do not imply released projects or one-click deployment.
